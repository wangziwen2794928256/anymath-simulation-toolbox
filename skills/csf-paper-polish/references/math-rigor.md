# 数学严谨性规范（润色/建模共用）

面向应用数学与建模论文。目标：可读、自洽、可复现，断言“要么显然、要么给出证明/算例”。

## 1. 结构自洽（self-contained）
- 定义先于使用；符号先定义后出现；一个符号只对应一个含义。
- 索引、上标、常数、变量严格区分，不重载（如 $i$ 不既作订单又作工序）。
- 公式是句子的一部分，要加标点；公式后跟解释“式中各量含义”。

## 2. 命题层级（可选项，建模论文用少量）
- 主结果叫**定理**（少用）；支撑主结果的中间结果叫**引理**；由主结果直接推出的叫**推论**；独立但次要的叫**命题**。
- 命题单独成行、正文引用；证明用“证明.”开头、“∎”结尾；指出假设在证明中哪里被用到。
- 数值型结论不用“定理”包装，直接给表格+不确定度。

## 3. 断言与证明（逐步推导，不许贴一级公式）
- 推导必须从定义出发，逐步写出：定义→依据假设化简→中间式→最终式，每步标注依据；关键机制给分量式或逐项推导。
- 禁止只给结论式后直接写“由此可得”，中间步骤要落在纸面上。
- 每个数学断言要么显然，要么给出证明或算例验证；无法证明的写成“猜想/经验观察”。
- 推导用等式链，顺序正确，每步标注依据（定义/假设/化简/定理引用）。
- 检验手段：退化/极限情形、量纲分析、误差界、与已知结果对照。

## 4. 记号与写作禁忌
- 正文不用逻辑符号（∀ ∃ ⇒ ∧ ∨）、不用“≈ > =”代替文字连接。
- 不以公式开头写句子；公式间用文字隔开。
- 避免无功能词与符号；每个代词有明确先行词。

## 5. 模型假设与有效性域
- 每条假设写清“适用范围 + 被放宽后的影响”；假设过多处给敏感性。
- 结果必须带量纲与不确定度；性能改进必须有对比基线，禁用“效果很好”。

## 6. 竞赛论文落地清单
- [ ] 符号表：符号/含义/单位/来源四列齐全
- [ ] 每个模型：假设 → 定义 → 逐步推导（每步依据）→ 求解步骤 → 算例 → 误差/敏感性 → 小结
- [ ] 至少 1 条“命题/性质”并给出证明或算例（如 SPT 最小化单机平均流经时间、EDD 最小化最大延期）
- [ ] 数值结果带均值±标准差与重复次数
- [ ] 极限/退化情形做一致性验证
