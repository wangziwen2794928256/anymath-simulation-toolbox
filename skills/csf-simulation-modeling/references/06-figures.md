# 图表规范（Nature / 顶刊顶会美术风格）

目标：让评委扫一眼图就感觉“这是能发的水平”。**科学图的核心是信息可读性与饱满度，不是花哨**。

## 1. 硬性规格（Nature 家族规范）
- 字体：无衬线（Helvetica / Arial），全篇统一；面板标签用 a/b/c 小写。
- 字号：正文 7–9 pt，轴标签 8–10 pt，图内文字最小 5 pt（印刷）→ 竞赛建议 8–11 pt。
- 尺寸：单栏约 89 mm、1.5 栏约 120 mm、双栏约 183 mm（按《论文规范》页宽换算）。
- 分辨率：栅格 ≥300 dpi；矢量优先（PDF/EPS/SVG）。
- 颜色：RGB；**色盲友好**（Okabe-Ito / Wong Nature Methods 2011）；避免红绿并用。
- 背景：白底；面板间留白充足；不要无意义渐变背景。

## 2. 语义配色（Nature 风，让“谁好谁坏”一眼可见）
| 角色 | 颜色 | 用途 |
|---|---|---|
| 主方法/最优解 | 深蓝 `#0F4D92` | 强调“本文方法/最优策略” |
| 基线/对照 | 中性灰 `#7F7F7F` | 对比对象，不抢戏 |
| 瓶颈/关键/告警 | 红 `#D62728` | 标出瓶颈、风险、关键节点 |
| 次优/辅助 | 橙 `#E69F00` / 绿 `#009E73` | 多策略区分 |
| 填充/分布 | 淡蓝 `#A6C8E8` 等低饱和 | 面积/直方/热图 |

完整色盲安全 8 色（Okabe-Ito）：
`#E69F00 #56B4E9 #009E73 #F0E442 #0072B2 #D55E00 #CC79A7 #000000`

## 3. 饱满度 = 信息密度 + 层次
- **每张图讲一件事**：一图一结论，多面板围绕同一结论展开（a 机制、b 主结果、c 对比、d 敏感性）。
- 图必配：轴标题 + 单位、图例、刻度内向外、误差棒（mean±std）、显著性标注（* / ** / *** 或 p 值）。
- 关键差异要“显式标注”：箭头、Δ 值、百分比提升，别让评委自己算。
- 热图/轨迹类加 colorbar 和单位；时间序列标关键事件竖线。

## 4. 本赛道常用图与画法（matplotlib 实现见 `assets/plotting/nature_style.py`）
| 图型 | 用途 | 要点 |
|---|---|---|
| 多面板 line + 误差带 | 指标随时间/回合变化 | fill_between 置信带，主方法深色加粗 |
| 对比 bar（带误差棒+显著性） | 策略/算法 KPI 对比 | 主方法用语义蓝，基线灰 |
| 收敛曲线 | RL/优化收敛 | 平滑 + 阴影，标最佳值虚线 |
| 敏感性 tornado/曲线 | 参数对 KPI 影响 | 排序 + 基准线 |
| Gantt 甘特图 | 调度/工序排布 | 按机器分组，颜色区分工件/任务 |
| 热图 | 状态-时间、拥塞、流量 | 色盲安全 cmap，加 colorbar |
| 智能体轨迹/快照 | ABM 涌现/疏散 | 稀疏箭头 + 起终点标注 |
| 框架图 | 模型/算法流程 | 图形化、对齐、统一圆角/箭头 |

## 5. 生成后自检（每张图过一遍）
- [ ] 图题说明“结论”，不重复轴标签
- [ ] 无红绿并用的歧义配色；黑白打印仍可区分（线型/标记区分）
- [ ] 轴有物理单位；对数轴已说明
- [ ] 误差棒/显著性齐全；样本量注明
- [ ] 字体统一、≥可读字号、面板标签齐全
- [ ] 输出 PDF/SVG 矢量 + PNG(300dpi) 双份
- [ ] 图与正文“图 1/表 1”编号对应，正文每图都有引用

## 7. 嵌入排版的坑（自检中发现）
- 图插入 Word/LaTeX/reportlab 时**显式给宽高**（按像素宽高比换算），别用“自动高度”，否则可能被判定过大导致排版错误。
- 图题放图下方居中、表题放表上方；图表编号与正文引用一一对应（“图 1 / 表 1”）。
- 多图并排用统一画布（`nature_style.multi_panel()`），面板标签 a/b/c 放左上角。
- 柱状图的数值标注放在误差棒上方，显著性星号放更高处，避免叠字。

## 8. 自检中踩到的 cmap 坑
- matplotlib 的 `Greys` 是“白→黑”，`gray` 是“黑→白”。画二值掩膜图（墙/背景）推荐：
  `ax.imshow(np.where(mask, 1.0, 0.0), cmap="Greys", vmin=0, vmax=1)`，墙=黑、背景=白，一眼可读。
- 热图用 `viridis`（线性感知、色盲安全），不要用 `jet`。

## 9. 顶刊级 Method 图与复合组图（图要有叙事）

简单折线/箱线只能当“结果图”，不够。每个竞赛论文至少配 1 张 **method/framework 图**（把模型/算法流程画出来）与若干 **复合组图**（多面板围绕同一结论）。

### 9.1 Method / framework 图（用 matplotlib 画框图）
- 用圆角矩形表示阶段/模块，箭头表示数据/控制流，同层同色、层级清晰。
- 调色沿用语义色：主流程深蓝、关键/瓶颈红、数据流灰、辅助橙/绿。
- 工具：`nature_style.draw_box / draw_arrow / panel_label`，或 Graphviz/PPT 后导出矢量。
- 必备：每个模块内写“做什么”，箭头上写“什么量在流动”（如“位置/排队长度”）。

### 9.2 复合组图（一张图讲完整故事）
- 用 `multi_panel` + 子图字母 `(a)(b)(c)(d)`，典型组合：
  - (a) 机制/框架；(b) 主结果曲线；(c) 策略对比；(d) 敏感性。
- 面板之间共享同一视觉语言：同色同符号=同方法，同轴=同量纲。
- 主结果面板用语义蓝加粗，基线灰，关键点红标。

### 9.3 图题与字号（硬性）
- 图题居中；图内所有文字字号 ≤ 正文，且 8–10pt 之间。
- 图内文字不得与数据/柱体/曲线粘连；留白不足就放大画布或减小标注。
- 导出后逐图放大检查“粘连、越界、字体大小不一致”。

## 10. 顶刊设计规范（源自 figures4papers / engineering-figure-agent 蒸馏）

### 10.1 核心风格
- 极简、高对比、白底；面板结构清晰，不用拼贴装饰；图例无边框；标签短而专业。
- 语义用色：蓝=主方法/中心机制，绿=改善/有利，红=基线/竞争/不利，灰=底衬/背景，金=唯一强调点。
- 全图同一颜色=同一含义，跨面板保持一致。

### 10.2 调色板（`nature_style.PUB_PALETTE`）
主蓝 `#0F4D92`、次蓝 `#3775BA`、绿 `#8BCF8B`、红 `#B64342`、灰 `#CFCECE/#4D4D4D`、强调金 `#FFD700`、青 `#42949E`、紫 `#9A4D8E`。
- 一组序列用 `PUB_SERIES = [#0F4D92,#8BCF8B,#B64342,#42949E,#9A4D8E,#4D4D4D]`。

### 10.3 常见图版式（prompt 化）
- 分组对比柱：黑色描边、紧凑图例、短指标名、y 轴压缩到能看出差异、必要时柱顶标数值。
- 趋势面板：2–4 条主曲线、线宽一致、可选置信带、弱网格、密集区外放图例。
- 热图/矩阵：干净格网、克制 colormap、行列标签可读、简单 colorbar。
- 多面板：数据面板聚在一起，留一个空面板放图例，面板边距/标题/标签位置对齐。
- 打印安全：多组同色系时加描边/纹理，不靠红绿区分。

### 10.4 中文标签（含中文图）
- 中文标签可直接入图，但要短、清晰、可读；不放大段中文。
- 保留标准英文符号/公式/缩写（FFT、CNN、loss、x、y、t 等），不强翻。
- 图内中文用大标签区、强间距、高对比；框图内文字水平居中。

### 10.5 架构图 / 主图（method hero figure）
- 用 `draw_box/draw_arrow` 画模块与因果流；模块内写“做什么”，箭头上写“流动什么量”。
- 分层/分阶段用同色系深浅区分，关键瓶颈用红、主流程用蓝。
- 一图一结论，图例放数据最密区之外。

### 10.6 导出
- `finalize_figure(fig, path, formats=("pdf","svg","png"))`：PDF 矢量 + SVG 可编辑 + PNG 300dpi，白底。
- 嵌入论文时字号 8–9pt（`apply_publication_style(font_size=8)`），单独成图时 14–16pt。
