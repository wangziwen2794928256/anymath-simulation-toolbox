# A 题领域作战手册（多智能体复杂系统仿真）

A 赛道命题落在五个领域之一。本手册给出每个领域的**标准模型、关键方程、真实参数范围、验证基准、典型图型与叙事套路**，拿到赛题先对号入座，再按套路建模型、配图、行文。文献锚点用于 related work 与“为什么选这个模型”。

## 0. 通用七步（任何 A 题都走）
1. 归类到下面五个领域之一；2. 取该领域标准模型做基线；3. 写关键方程与参数（用真实参数范围）；4. 实现可复现仿真；5. 用该领域验证基准/极限/解析对照校验；6. 加入一个创新机制（拥塞感知/异构/学习/协同）；7. 按“图型-叙事配对”出图成文。

## 1. 人群疏散 / 行人动力学

**标准模型（按复杂度递进）**
- 元胞自动机 + 地场（Floor Field CA）：Burstedde 2001；Kirchner & Schadschneider 2002。静态地场引导出口，动态地场刻画足迹。
- 社会力模型（Social Force）：Helbing & Molnár 1995。连续空间，受力驱动。
- ABM + 出口选择/情绪/领导-跟随：Pan et al.；Hassanpour & Rassafi。

**社会力关键方程**
加速度 $\frac{\mathrm{d}\mathbf{v}_\alpha}{\mathrm{d}t}=v_\alpha^0\frac{\mathbf{e}_\alpha-\mathbf{v}_\alpha}{\tau}+\sum_{\beta}\mathbf{f}_{\alpha\beta}+\sum_w\mathbf{f}_{\alpha w}$，其中期望方向 $\mathbf{e}_\alpha$、松弛时间 $\tau$；行人-行人斥力 $f_{\alpha\beta}=A\exp[(r_{\alpha\beta}-d_{\alpha\beta})/B]\mathbf{n}$；行人-墙斥力同理。

**真实参数范围（用于初始化与敏感性）**
- 期望速度 $v^0=1.34$ m/s，最大速度 $1.3v^0$；松弛 $\tau=0.5$ s。
- 斥力强度 $A=2000$ N、范围 $B=0.08$ m；$V_{\alpha\beta}=2.1$ m²/s²，$\sigma=0.3$ m。
- 步长 $d=a+bv$，$a=0.36$ m，$b=1.06$ s。
- 1 m 门宽比流量 $\approx 0.73$ p/(m·s)；自由流速度 $1.2$–$1.5$ m/s。

**验证基准**
- 基本图（fundamental diagram）：速度-密度、流量-密度关系，与 Weidmann 曲线对照。
- 门/瓶颈流量与实验比流量（0.73 p/m/s）对照。
- 总疏散时间与既有实验/规范（如 SFPE）对照。

**典型图型 → 叙事**
- 场景平面+出口布局图 → “模型建立”开头。
- 轨迹/快照图（t=0/中/后）→ “机制与涌现”段。
- 剩余人数-时间曲线 + 置信带 → “主结果”。
- 出口流量/排队-时间热图 → “瓶颈与出口选择”。
- 密度-速度基本图 → “模型校验”。
- 出口选择策略对比柱状图 → “策略对比”。

**叙事套路**：机理（受力/规则）→ 参数校准 → 基线疏散曲线 → 拥塞/瓶颈识别 → 改进策略 → 敏感性。

## 2. 物流集群 / 车间调度

**标准模型**
- 离散事件仿真（DES）+ 分派规则：FCFS/SPT/EDD/SLACK/CR/PR+CR。
- 排队网络：Jackson 网络、Little 定律 $L=\lambda W$、CONWIP 控制。
- 元启发式：GA/NSGA-II/SA；学习式：析取图 GNN+DRL（Zhang 2020 L2D）。

**关键方程**
- 吞吐 $TH$、平均 WIP、平均周期时间满足 Little 定律 $WIP=TH\times CT$。
- 设备利用率 $U_m=\frac{\sum_j p_{jm}}{C_{\max}}$；瓶颈：$U_m$ 最高且队列持续非空。
- 完工时间递推 $C_{jm}=\max(C_{j,m-1},A_m)+p_{jm}$；下界 $C_{\max}\ge\max_m\sum_j p_{jm}$。

**验证基准**
- 单机情形与解析最优对照（SPT 最小化平均流经时间、EDD 最小化最大延期，含证明）。
- 与理想上界（忽略搬运/清洗）对照算作业效率。

**典型图型 → 叙事**
- 产线布局/物流路径图 → 模型建立。
- Gantt 甘特图 → 调度结果。
- 各工位利用率柱状图（标瓶颈）→ 瓶颈识别。
- WIP/吞吐-时间曲线 → 稳态性能。
- 规则/算法对比柱状图 → 策略对比。
- 参数敏感性 tornado → 稳健性。

## 3. 供应链多主体

**标准模型**
- 系统动力学（存量流量）+ 啤酒游戏（Sterman 1989）刻画牛鞭效应。
- 多级串行供应链 ABM：供应商-制造商-分销商-零售商，各用补货策略。
- MARL：以抑制牛鞭效应 + 抗风险为奖励（2025/2026 IJPR、ACM 工作）。

**关键方程**
- 需求方差逐级放大：牛鞭效应 $=Var(订单)/Var(需求)$。
- EOQ 补货 $Q^*=\sqrt{2DS/H}$；提前期 $L$ 步。
- 奖励 $r = -c_1 成本 - c_2 缺货 - c_3\,牛鞭惩罚 - c_4 库存$。

**典型图型 → 叙事**
- 供应链结构/信息流图 → 模型建立。
- 各环节订单量-时间曲线（展示放大）→ 牛鞭效应。
- 牛鞭效应比值柱状图（基线 vs MARL）→ 主结果。
- 消融（去掉牛鞭惩罚项的变化）→ 贡献。

## 4. 传染病 / 行为演化

**标准模型**
- 仓室 SIR/SEIR：$\dot S=-\beta SI,\ \dot I=\beta SI-\gamma I,\ \dot R=\gamma I$，$R_0=\beta/\gamma$。
- 网络/ABM：接触网络 + 个体异质；校准用 SMC / BiLSTM 代理（epiworldRcalibrate）。
- 意见演化：投票者模型、Deffuant 有界置信。

**验证基准**
- ABM 与 SEIR ODE 对照（同参数下曲线一致）；$R_0$ 与文献值对照。
- 数据校准：拟合真实感染曲线，报告参数后验。

**典型图型 → 叙事**
- 传播网络/接触图 → 模型建立。
- 感染/康复人数-时间曲线 + 多 seed 置信带 → 主结果。
- 峰值/最终规模随参数变化热图 → 敏感性。
- 干预策略对比曲线 → 策略。

## 5. 多智能体协同 / MARL

**标准方法**
- 值分解：IQL/VDN/QMIX/QPLEX；策略：MADDPG/MAPPO。
- 基准环境：MPE、SMAC/SMACv2、PettingZoo；框架 EPyMARL/PyMARLzoo+。
- 参数共享 + agent-id one-hot（同质）；异质用分离网络。

**关键点**
- 离散合作 → QMIX/MAPPO；连续/混合 → MADDPG；最稳 → MAPPO/IPPO。
- 训练曲线（episode return）报告 mean±std（≥3 seeds）；与规则基线对照。

**典型图型 → 叙事**
- 环境/任务示意图 → 问题设定。
- 训练收敛曲线 + 阴影 → 训练稳定性。
- 奖励/成功率对比柱状图（规则 vs 各 MARL）→ 主结果。
- 策略行为快照（协同涌现）→ 机制。

## 6. 图-叙事配对总表（A 题通用）

| 图型 | 配在哪一段 | D-A-C 落点 |
|---|---|---|
| 场景/系统示意图 | 模型建立开头 | D 描述构成；A 说明资源耦合；C 引出建模难点 |
