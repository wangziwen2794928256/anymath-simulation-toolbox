# 科学推理链（先于一切结构）

结构、图表、页数、公式数都不是科学性本身。科学性 = 一条从现象到机制的、**可证伪的、递进验证的**推理链。拿到赛题，先产出这条链，再谈结构。

## 推理链七步（拿到赛题第一件事，不许跳过）

1. **现象→问题本质**：把赛题一句话翻译成“本质是什么问题”。句式：`这不是 X 场景，而是 Y 类问题`。例：不是“疏散”，而是“带容量约束的分布式资源分配”。

2. **机制（一句话点破矛盾）**：为什么现状不好？矛盾是什么？用一句话写清。例：`个体选择拥堵出口给后来者强加等待成本——拥堵外部性/信用分配`。

3. **可证伪假设 H1..Hn**：不是“我建模型”，而是“我要验证什么”。每条假设必须能被一个实验证实或证伪。例：
   - H1：均衡分配优于就近分配；
   - H2：动态反馈优于静态；
   - H3：存在最优反馈权重 λ。

4. **为假设选模型**：模型是为了验证 H1..Hn 而选的，写一句“为什么用这个模型、不用那个”。例：用离散时间多智能体+宏观出口容量，因为要研究分配策略而非局部动力学。

5. **递进式实验**：每个实验验证一条假设，形成因果链，不是并列堆结果。例：基线→验H1→验H2→验H3→泛化。

6. **解释成功与失败**：每个结果（含失败）都要回答“为什么”。失败尤其宝贵——它反过来论证机制。例：独立学习塌缩→因信用分配→论证 H1 并引出 CTDE。

7. **连续性**：全文是一条链，章节是链的节点，节与节之间有因果衔接（“因为 H1 成立，故进一步问 H2…”），不是独立成块。

## 硬性红线（防“为堆而堆”）

- 先有推理链，再谈章节/图表/页数；推理链未定，不许排结构。
- 假设必须“可证伪且被实验验证”，禁止写纯装饰性的“范围限定式”假设。
- 每个实验回答一条假设；实验之间写清递进关系。
- 每个结论（含失败）写“为什么”，禁止只报数值。
- 简介/摘要不是“重述题目+罗列方法”，而是“问题本质+机制+核心发现”的浓缩。

## 两个通用建模手法（资源分配/调度/拥堵类 A 题必用）

### 手法一：排队机制闭合推导
任何“容量受限资源分配”题（疏散出口、AGV、机器、缓存），都要给出**闭合的数量级解释**，而非只报仿真值：
1. 写服务率 $\mu_e = w_e q$（容量×单位速率）。
2. 算理想均衡分配（按容量比例分摊负荷）。
3. 算策略导致的过载人数与额外排队时间 $\Delta T = 过载量/\mu_e$。
4. 合成闭合估计：下界 $+\Delta T\approx$ 实测值，说明“为什么是这个量级”。

### 手法二：Pigou 拥堵定价视角
把“代价=个体项+拥堵项”解释为**边际成本定价**：$d_i+\lambda Q_e$ 是 $\tau_e\propto Q_e/\mu_e$ 的一阶线性近似，$\lambda$ 对应 $1/\mu_e$ 缩放。这一视角同时解释“为何存在最优 $\lambda$”（太小外部性未内化、太大过度收费绕行），并把启发式规则升华为有理论根基的方法。
