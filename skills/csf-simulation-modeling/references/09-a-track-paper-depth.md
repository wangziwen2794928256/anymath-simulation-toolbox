## 2. 多智能体形式化（第 3 章核心，不能省）
- **环境**：状态空间 $S$、动作空间 $A=\prod_i A_i$、转移 $P(s'|s,a)$、观测函数 $O_i(s)$、奖励 $R_i$ 或全局 $R$。
- **智能体元组**：$(\mathcal{O}_i,\mathcal{A}_i,\pi_i)$，同质则参数共享，异质则分离策略；$\pi_i(a_i|o_i)$ 为策略。
- **交互拓扑**：图 $G=(V,E)$ 或空间邻域；写明“谁影响谁、信息如何传播”。
- **协同目标**：全局目标 $\max J(\pi)$ 或分散目标 + 一致性约束；写清 credit assignment（信用分配）问题。
- **涌现与集体行为**：密度、流量、拥塞、协调率等宏观量与微观规则的定量联系。

## 3. 数理深度（第 4 章，不能只有公式）
- 随机过程/排队：到达与服务分布、Little 定律 $L=\lambda W$、利用率与下界。
- 机制推导：从个体规则推到宏观量（如社会力→基本图；补货策略→牛鞭效应方差放大）。
- 理论性质：命题/引理 + 证明（如 SPT/EDD 最优性、下界、收敛性、纳什均衡存在性）。
- 复杂度：状态/动作维度、每步计算量、可扩展性；何时用精确/启发式/学习式。
- 消融与假设敏感性：每个机制/参数扰动对指标的影响。

## 4. 代码与算法深度（第 5 章，不能只写“用 Python 求解”）
- **数据结构**：事件表/优先队列、空间网格/KD-tree、邻接表、FIFO 队列；说明选型理由。
- **算法伪代码**：逐步伪代码 + 每步复杂度；主循环、策略更新、出口/资源服务。
- **可复现**：随机种子覆盖 numpy/torch、环境冻结、超参表、`run_id` 与产物对应。
- **基线族**：规则基线 ≥1、经典启发式 ≥1、学习式 ≥1；报告 mean±std（≥3 seeds）。

## 5. 实验深度（第 6 章）
- 主结果：策略对比表 + 过程曲线 + 时空热图。
- 消融：去掉某机制（拥塞感知/通信/记忆）看指标变化。
- 敏感性：关键参数 tornado / 扫描曲线。
- Monte Carlo：多次重复报均值±std；两组间 t 检验 / Wilcoxon 显著性。
- 验证：与解析解/下界/实验数据（如基本图、比流量）对照。

## 8. 两个通用结构（消融系统化 + 学习式对照）

### 8.1 系统化消融（通用，非针对某题）
消融要沿**多个轴**展开，并同时给「图 + 大表」，不能只画三根柱子：
- **组件轴**：完整方法 vs 去掉某组件（-拥塞项 / -动态重分配 / -全局反馈 / -学习模块）。
- **超参轴**：关键参数扫点（如 λ∈{0,1,2,3,5,8}）或重分配频率扫点（静态/100/40/10/1 步）。
- 每个轴输出：折线（连续轴）+ 柱状（离散轴）+ 一张大表（每行一个设置、每列一个指标）。
- 图注写清“贡献差值”：如“动态重分配贡献 48.3% 的时间缩减”。

### 8.2 学习式方法对照（IQL vs CTDE）
- 必设两条学习曲线：独立学习（IQL，个体奖励）与集中训练-分散执行（VDN/QMIX，全局奖励）。
- 关键对比指标：协调度（出口流量 Gini / 方差）+ 总疏散时间。
- 诚实的失败也要写：独立学习在协同任务中常塌缩到单一出口（信用分配失败），这正论证集中式/全局反馈的必要性。
- 实现用 EPyMARL / PyMARLzoo+（QMIX/MAPPO 现成实现），不要手写值分解（手写易发散）。
