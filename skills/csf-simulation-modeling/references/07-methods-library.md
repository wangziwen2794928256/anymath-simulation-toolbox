# 方法总库（本问题类专用：工程调度 / 生产系统 / 复杂系统仿真 + AI）

只收录“智能流水车间、生产调度、物流集群、人群/多智能体复杂系统、数据驱动仿真”这一大类工程与 AI 问题里的方法。按“问题类型 → 首选方法 → 备选”组织，禁止塞入无关的通用 ML 大杂烩。文献出处统一见 `05-literature.md` 第 I 节。

## 0. 本问题类的五个子类
1. **组合优化 / 调度**：流水车间、作业车间、柔性车间、并行机、AGV/搬运、排班。特征：离散决策、约束多、目标为 makespan/延期/成本。
2. **离散事件系统仿真**：产线、仓储、排队、物流。特征：随机到达/加工、资源竞争、阻塞。
3. **多智能体协同 / 群体演化**：疏散、供应链多主体、博弈。特征：个体决策+涌现。
4. **数据驱动仿真优化**：真实数据标定参数、代理模型、数字孪生。特征：仿真昂贵、需校准。
5. **学习型调度 / 动态决策**：DRL、GNN、构造式神经网络。特征：需实时或在线决策、状态图结构。

## 1. 精确方法（先验证可解性与上界）
| 方法 | 何时用 | 实现 | 出处 |
|---|---|---|---|
| 数学规划 MILP | 小规模、约束线性、要精确最优 | Gurobi / CP-SAT | pinedo2016 |
| 约束规划 CP | 工序顺序、机器-工件分配、强约束 | OR-Tools CP-SAT / IBM CP Optimizer | baker2019 |
| 动态规划 | 阶段可分解、状态空间小 | 手写 DP | pinedo2016 |

要点：小规模先跑 MILP/CP 拿最优解或上下界，作为启发式/学习的验证基线。

## 2. 构造式与分派规则（基线，永远先做）
| 规则 | 定义 | 适用 |
|---|---|---|
| FCFS | 先到先服务 | 基线 |
| SPT/LPT | 最短/最长加工时间 | 最小化流经时间 |
| EDD | 最早交期 | 最小化最大延期 |
| SLACK | $d_j - t - q_j(t)$ 最小 | 兼顾交期与剩余量 |
| CR | $(d_j-t)/q_j(t)$ 最小 | 交期紧迫度 |
| PR+CR | $w_j\cdot CR$ 最小 | 有优先级订单 |
| 组合规则 | 两级/加权组合 | 多目标权衡 |

出处：graham1979。要点：分派规则是解释性最强、零训练成本的基线，任何学习式方法都要与之对比。

## 3. 元启发式（组合优化主力）
| 方法 | 何时用 | 关键点 |
|---|---|---|
| 模拟退火 SA | 单目标、快速降温 | 邻域+温度；kirkpatrick1983sa |
| 禁忌搜索 TS | 避免循环、局部深度搜索 | 禁忌表；glover1989ts |
| 遗传算法 GA | 编码为序列/分配 | 交叉变异；reeves1995ga |
| 粒子群 PSO | 连续变量或可实数编码 | kennedy1995pso |
| 差分进化 DE | 连续参数优化 | storn1997de |
| 大邻域搜索 LNS | 大规模、可破坏重建 | 破坏+修复 |

要点：编码方案决定成败。调度常用“工序排列编码 + 贪心解码到最早可行时刻”。

## 4. 多目标优化
| 方法 | 何时用 | 出处 |
|---|---|---|
| NSGA-II | 2–3 目标帕累托 | deb2002nsga2 |
| NSGA-III | 4 个以上目标 | deb2014nsga3 |
| MOEA/D | 多目标分解为标量子问题 | zhang2007moead |
| ε-约束法 | 目标少、要精确边界 | — |

要点：makespan 与总延期通常冲突，用帕累托前沿展示权衡，再按场景选点。

## 5. 仿真建模与仿真优化
| 技术 | 何时用 | 要点 |
|---|---|---|
| 离散事件 DES | 排队/资源/事件流 | simpy 或事件表；law2015, banks2010 |
| 输入建模 | 拟合到达/加工分布 | 分布拟合 + 卡方/K-S 检验 |
| 预热与重复 | 消除初始偏差与随机性 | 预热期 + 多 seed 报告 mean±std |
| 仿真优化 OvS | 在仿真上寻优 | 元启发式+仿真评估，或排名选择 |
| 方差缩减 | 对比策略 | 公共随机数 CRN |

要点：随机性可控时用公共随机数，策略对比更公平。

## 6. 机器学习（代理模型 / 校准 / 特征）
| 方法 | 何时用 | 实现 |
|---|---|---|
| 高斯过程 GP | 仿真昂贵、要不确定度 | scikit-learn / GPyTorch |
| 随机森林/XGBoost | 特征工程、快速代理 | sklearn |
| 主成分/聚类 | 状态压缩、场景分类 | sklearn |
| 贝叶斯优化 BO | 少样本调参/校准 | Optuna / BoTorch；snoek2012bo |
| 贝叶斯校准 | 用观测数据标定仿真参数 | kennedy2001calibration |

要点：ML 在“仿真”题里的正确定位是**代理/校准/降维**，不是替代机理。

## 7. 深度强化学习（单智能体，动态决策）
| 方法 | 何时用 | 出处 |
|---|---|---|
| DQN | 离散动作、状态低维 | mnih2015dqn |
| Double DQN | 减少高估 | vanhasselt2016ddqn |
| PPO | 稳定、样本利用率高 | schulman2017ppo |
| DDPG | 连续动作 | lillicrap2016ddpg |
| TD3 | 连续动作、减少高估 | fujimoto2018td3 |
| SAC | 连续动作、熵正则、鲁棒 | haarnoja2018sac |

要点：调度问题多为离散动作，DQN/PPO 起步；奖励必须与 KPI 单调对齐。

## 8. 多智能体强化学习 MARL
| 方法 | 类型 | 何时用 | 出处 |
|---|---|---|---|
| IQL | 独立学习 | 基线 | tan1993iql |
| VDN | 值分解可加 | 合作 | sunehag2018vdn |
| QMIX | 单调混合 | 合作、部分可观测 | rashid2018qmix |
| QPLEX | 更灵活分解 | 复杂信用分配 | wang2021qplex |
| MADDPG | CTDE 连续 | 混合动机 | lowe2017maddpg |
| MAPPO | CTDE on-policy | 合作最稳 | yu2022mappo |

要点：能写成“合作任务+全局奖励”先用 QMIX/MAPPO；不确定时 MAPPO/IPPO 最稳。框架用 EPyMARL / PyMARLzoo+，别手写。

## 9. 图神经网络 + 学习式调度（生产调度 SOTA）
- **析取图建模**：工序为节点，机器/优先级为边，GNN 编码。
- **Learning to Dispatch (L2D)**：GNN 编码 + DQN 分派；zhang2020l2d。
- **GNN+DRL 综述**：chen2024gnnjsp。
- 要点：小规模先用析取图+GAT+PPO 打样，来不及就 GA/NSGA-II + 规则，论文里把 GNN 作为改进方向。

## 10. 神经网络构造式组合优化（端到端）
- Pointer Network：序列决策；vinyals2015ptrnet。
- Attention Model：路由类 SOTA；kool2019am。
- 要点：适合“序列生成”型（路径/排序），不适合约束复杂的车间；车间用“GNN 编码 + 规则/RL 解码”。

## 11. 数据驱动仿真优化与数字孪生
- 闭环：`真实数据 → 分布/参数标定 → 仿真 → 误差 → BO 迭代`。
- 五维数字孪生（物理+虚拟+服务+数据+连接）；仿真优化用 BO+GP 代理（snoek2012bo）。
- 要点：答辩/论文的“高级感”来源，但先保证机理模型可信。

## 12. 选型决策矩阵（按问题特征 → 首选 → 备选）

| 问题特征 | 首选 | 备选 | 不用 |
|---|---|---|---|
| 小规模、要精确解 | MILP/CP | 枚举/DP | 深度学习 |
| 中等规模单目标调度 | 分派规则 + GA/SA/TS | PPO/DQN | 大语言模型 |
| 多目标调度（makespan+延期） | NSGA-II/III | MOEA/D | 单目标 SA |
| 随机到达/加工，要看稳态指标 | 离散事件仿真 + 多重复 | 仿真优化 OvS | 纯解析 |
| 动态实时分派/重调度 | 规则 / PPO / GNN+RL | 元启发式重调度 | 静态 MILP |
| 多主体协同/疏散 | ABM + 规则基线，再 MARL | 元胞自动机/社会力 | 单智能体 DQN |
| 仿真昂贵、要校准 | BO + GP 代理 | 贝叶斯校准 | 网格搜索 |
| 有真实数据、要预测/标定 | 回归/XGB/GP | 神经网络 | 纯机理拍参数 |
| 序列生成型（路径/排序） | Attention Model / PtrNet | 强化学习 | GNN（非图结构） |
| 图结构状态（车间） | GNN + DRL | GA + 规则 | Transformer 裸用 |

## 13. 反模式（别踩）
- 能用规则/精确解说清的问题，不要为“高级”硬上深度学习。
- 任何 ML/RL 都要配规则或精确基线，否则评委不认可。
- 不把大语言模型当主求解器：不可复现、慢、贵，只能作行为机制或论文讨论。
- 不手写 MARL 框架：直接用 EPyMARL/PyMARLzoo+/SB3。
- 不做无数据支撑的“预测”：没有数据就做机理+假设+极限验证。

## 14. 与本库配套的决策顺序
1. 归类到第 0 节五子类之一；
2. 查第 12 节矩阵得首选与备选；
3. 先做首选中的“可解释基线”，再加备选做对照；
4. 记录 baseline/种子/超参，形成可复现对比。
