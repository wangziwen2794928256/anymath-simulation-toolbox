# 分阶段交付与门禁边界

建模阶段先检查模型规格、边界、单位、更新顺序、守恒、手算基线与独立验证。无需为了通过论文格式检查填充章节或图表。

| 检查 | 工具 | 能证明什么 / 不能证明什么 |
|---|---|---|
| 机理库 | csf_mechanism.py --check | 引用键和字段一致；不能证明文献支持本题推导 |
| 方法库 | csf_select.py --check | 方法/前提覆盖；不能证明算法适用或包已安装 |
| 选型前提 | csf_select.py --context ... --plan | 按声明事实排除冲突与待补；事实需另行查证 |
| 原始统计 | csf_evidence.py | 记录合法性、逐种子统计和配对覆盖；不能验证事件文件内容或实验独立性 |
| 数值/格式 | csf_gate.py --lang en/zh | 文本、引用与数值候选匹配；不能替代推导、原始证据和模型审计 |
| 图表论证 | csf_narrative.py / figure_contract_check | 图表契约字段与结构；仍需读图验证数据、量纲、结论 |
| 平台 | csf_interop.py / csf_parity.py | 静态兼容提示与指定输入对拍；仍需实际环境测试 |
| 论文编译 | csf_build.py | 编译日志、引用、版式告警；需逐页渲染检查 |

旧文档的 18 页、5 图、4 表、至少 3 类 baseline 是成稿默认建议，除非已核实为目标提交要求，否则按问题规模调整。基线应覆盖有效方法和信息公平性，不能为数量凑上无关 MARL。相同输出可能来自方法等价，先验证并解释，再合并呈现；不能据此直接断定编造。

默认英文壳走 csf-paper-polish；使用者要求中文则切换相应模板。实际数字由保存的原始记录生成，单位和误差定义紧邻图表。未收敛、超时、删失必须另列，不把 MAXT 当完成时间。

内部示例只验收其声明的规模与证据。短篇合成示例不宣称通过完整赛事论文门禁，不把论文形式、漂亮图表或库引用键当成已完成现实验证。
