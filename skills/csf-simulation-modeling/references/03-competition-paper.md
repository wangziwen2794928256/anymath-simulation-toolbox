# 竞赛论文写作（评分导向）

评委先看**摘要和结果**，再看模型和数据。所以摘要要亮眼，结果要合理且带数值；模型不一定要复杂，但必须讲清楚“为什么选它、每个参数是什么、求解步骤是什么”。

## 1. 评分结构（2025 口径，2026 以《赛项说明》为准）
- 论文 **70%** + 演示视频 **30%**。
- 提交四件套：电子论文、承诺书、支撑材料、仿真视频（论文/承诺书/视频必需）。

## 2. 摘要（最重，一页内，约 1000 字）
- 必须包含：问题 → 方法（范式+算法）→ **每问的数值结果** → 创新点。
- 忌：出现公式、引用参考文献、第一人称、空话“效果良好”。
- 一等论文的摘要“每问必有具体数值”；三等论文常“只写方法不写结果”。

## 3. 正文结构（A 赛道）
1. 问题重述与分析（目标、约束、数据、KPI）
2. 模型假设（5–10 条，每条有现实依据）+ 符号说明
3. 模型建立（按 ODD：实体/状态/规则 → 数学描述 → 参数表标来源）
4. 仿真实现（流程/伪代码 + 模型校验）
5. 结果与分析（基线表 + 策略对比 + 敏感性 + 蒙特卡洛，每子问题末尾放检验段落）
6. 方案设计（把结论翻译成可落地的调度/治理方案）
7. 模型评价（优点/局限/改进）
8. 参考文献（规范引用，正文标注[1][3]）

## 4. 高分清单
- [ ] 摘要每问有具体数字
- [ ] 每个模型都有“为什么选它 + 参数含义 + 求解步骤”
- [ ] 每子问题末尾有敏感性分析 / 误差分析 / 检验（0.5–1 页）
- [ ] 有基线对照，创新点可证伪（比基线好在哪）
- [ ] 图表统一风格、编号、有图题，关键结果 4 位有效数字
- [ ] 代码在支撑材料，正文只放流程图/伪代码
- [ ] 视频：10 秒讲清问题+结论 → 运行动画 → 关键图表 → 创新点

## 5. 格式与红线
- 正文页数、页眉页脚、参考文献格式以当届《论文规范》为准（国赛常见：摘要一页内、正文一般 30 页内、附录含源程序、页码从摘要页起）。
- **原创性红线**：全文疑似 AIGC 比例、总相似比超标直接取消资格（2025 参考：AIGC>30% 或总相似比>50%）；引用必须标注。
- **AI 使用规定**：AI 可用于查资料、润色草稿，但最终论文必须自主实质性修改，不得大篇幅生成。
- 指导教师不得参与实质求解；不得跨校组队、一人多队。

## 6. 与 journal 版的区别（从现在就要留一手）
- 竞赛版：强调“完整解题 + 方案落地 + 视频展示”，可以多写过程。
- journal 版：强调“新颖性 + 方法贡献 + 可复现实验 + 与 SOTA 对比”，摘要/图/表要英文。
- 两者共享：模型、算法、实验数据、图表。所以竞赛时就把实验做成“可移植”的（保留 seed、超参、源码、指标）。

## 7. 初稿即 LaTeX + 详细推导

- 从第一版初稿就产出可编译的 `paper.tex`（用第二层 `csf-paper-polish` 的 `create_project.py` 生成工程），不交付纯 Word/Markdown 稿；文字、公式、图、表、参考文献全部在 `.tex` 中，编译即得 PDF。
- 模型章节必须含**逐步推导**：定义 → 依据假设化简 → 中间式 → 最终式，每一步标注依据；求解要有算法步骤（伪代码）与终止条件。
- 篇幅靠推导、子情形讨论、对比实验、敏感性分析支撑，不靠重复结论或放大图。
- 图：至少 1 张 method/框架图 + 若干复合组图（见 `06-figures.md` 第 9 节）；图题居中、图内字号 ≤ 正文、无文字粘连。

## 8. 内容量与参考文献目标（初稿就要定）

- 正文以官方上限为目标，默认参考国赛 30 页；模型章占总页 ≥60%，摘要与结论各一页内。
- 每个子问题五段齐全：模型建立→求解→问题结论→检验分析→小结；缺一段即内容量不足。
- **参考文献 10–15 篇为底线**，三类都要有：
  - 方法出处（如 NSGA-II、QMIX、ODD 的原始论文）≥3 篇；
  - 场景/领域代表作（调度、疏散、供应链）≥3 篇；
  - 2022 年后的前沿综述 ≥3 篇。
- 篇幅靠推导、子情形讨论、对比实验、敏感性分析支撑，不靠重复结论或放大图。
