# 例题 A：校园礼堂高峰疏散仿真与出口调度优化（A 题风格，含完整数据）

## 背景
某高校礼堂长 24 m、宽 16 m，设 3 个疏散出口，满座 400 人。高峰散场时人员集中离场，若均选择最近出口，易在个别出口形成拥堵。

## 数据
| 参数 | 取值 |
|---|---|
| 礼堂尺寸 | 24 m × 16 m |
| 出口 E1（左墙，中心 y=8 m） | 宽 1.6 m |
| 出口 E2（右墙，中心 y=8 m） | 宽 1.2 m |
| 出口 E3（下墙，中心 x=12 m） | 宽 0.8 m |
| 人数 N | 400 人 |
| 自由行走速度 v0 | 1.34 m/s |
| 出口单位宽度比流量 | 0.73 人/(m·s) |
| 初始分布 | 60% 近 E3 区域、25% 近 E2、15% 近 E1 |

## 任务
1. 建立多智能体疏散仿真模型，以“最近出口”为基线，计算总疏散时间与各出口流量。
2. 比较“最近出口”与“拥塞感知动态分配”两种策略。
3. 识别瓶颈出口，验证“调节出口宽度 / 分配权重”的优化效果。
4. 对人员密度与行走速度做敏感性分析。
